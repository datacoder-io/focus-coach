# مربی بازی (اسم موقت) 🎮

مربی زنده برای Dota 2 که **هر لحظه فقط یک کار** رو بهت می‌گه: چی بخری، کِی برگردی عقب، کدوم اسکیل رو بگیری، رون کِی میاد، کدوم آیتم نوترال رو برداری و با چه آیتمی جلوی دشمن‌ها رو بگیری.
همه‌چیز توی یه پنجره‌ی کوچیک روی خود بازی نشون داده می‌شه و با صدای فارسی هم گفته می‌شه.

> این پروژه هیچ ارتباطی با Valve نداره. Dota 2 علامت تجاری Valve Corporation است.

## شروع (۳ قدم)

1. [Node.js](https://nodejs.org) نسخه‌ی ۲۰ یا بالاتر رو نصب کن.
2. توی تنظیمات ویدیوی Dota، حالت نمایش رو بذار روی **Borderless Window**.
3. روی **`START.bat`** دابل‌کلیک کن. خودش اتصال به Dota رو نصب می‌کنه، Dota رو با تنظیم درست باز می‌کنه و پنجره‌ی کوچیک مربی رو روی بازی می‌ذاره.

فقط می‌خوای ببینی چه شکلیه؟ **`DEMO.bat`** رو اجرا کن.

## رنگ‌ها

| رنگ | یعنی |
|---|---|
| 🔴 قرمز (چشمک‌زن) | خطر! جونت کمه |
| 🟢 سبز | پولش رو داری، بخر |
| 🟡 زرد | تایمر نزدیکه (رون، تورمنتور…) |
| 🔵 آبی | یادآوری (اسکیل، Stash، نوترال…) |
| ⚫ خاکستری | مُردی، وقت خرید |

## نکته‌ها

- **پنجره‌ی کوچیک روی بازی:** کلیک‌ها از روش رد می‌شن و به بازی می‌رسن. برای جابه‌جا کردنش `Ctrl + Alt + M` رو بزن، بکشش، دوباره `Ctrl + Alt + M`. جاش ذخیره می‌شه.
- **شاپ:** اسم آیتم بعدی خودش کپی می‌شه. توی شاپ روی جستجو کلیک کن و `Ctrl + V` بزن.
- **تنظیمات و زبان صدا:** پنجره‌ی بزرگ (`http://localhost:3005`) ← ⚙️.
- **گوشی:** همون آدرس رو با IP کامپیوتر روی گوشی باز کن (همون وای‌فای).
- **تایمرها** و زمان آزاد شدن آیتم‌ها توی `config.json` هستن (برای پچ 7.41).

## هوش مصنوعی (اختیاری)

مربی دشمن‌ها رو از نوار بالای صفحه می‌شناسه و آیتم ضدشون رو پیشنهاد می‌ده.

**⭐ با لایسنس Pro:** لایسنس (`FC-XXXX-XXXX-XXXX-XXXX`) رو توی پنجره‌ی بزرگ، بخش ⚔️ دشمن‌ها، وارد کن. هیچ کلیدی لازم نیست.

**🔑 با کلید خودت:** یه کلید [OpenRouter](https://openrouter.ai) بگیر.
فایل `secrets.example.json` رو کپی کن، اسمش رو بذار `secrets.json` و کلیدت رو توش بذار. یا کلید رو توی پنجره‌ی بزرگ، بخش ⚔️ دشمن‌ها، Paste کن.
هزینه‌اش تقریباً **نیم سنت برای هر بازیه.** توی OpenRouter حتماً سقف خرج بذار.

## امنه؟

- از **Game State Integration**، یعنی سیستم رسمی Valve، استفاده می‌کنه. به حافظه‌ی بازی دست نمی‌زنه و **هیچ‌وقت به‌جای تو کلید یا کلیک نمی‌فرسته.**
- فقط اطلاعات هیروی خودت رو از Dota می‌گیره. وقتی AI روشن باشه، **فقط نوار بالای صفحه** (چهره‌ی ۱۰ هیرو) برای شناسایی فرستاده می‌شه.
